# Trainee Problem Submission

Solutions for the trainee problem set.

- [question_1](question_1/) — Logic Challenge: simulates the BOX machine described in the problem and prints `ANSWER - BOX A` and `ANSWER - BOX B`.
- [question_2](question_2/) — File Explorer: an in-memory file explorer CLI reading commands from stdin.

## Running

```bash
python question_1/solution.py
```

```bash
python question_2/solution.py < commands.txt
```
